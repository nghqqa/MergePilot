安全审查工作台

自托管的 PR 审查、安全发现管理和修复验证平台，带完整审计追踪。

✓ 只读审查 ✓ 审计追踪 ✓ Docker 部署 ✓ 组织标准检索 ✗ 自动 merge ✗ 完整 RAG ✗ 自动修复

核心能力

Review Agent

只读 PR 审查与安全阶段推导。七个权威阶段：REVIEWING → ACTION_REQUIRED → REMEDIATING → VERIFYING → PASSED → BLOCKED → STALE。

Console

实时控制台：运营总览、待处理队列、仓库浏览、PR 钻取、审计查询。服务端会话与仓库 allowlist。

Fixer / Verifier

隔离环境中的自动修复与独立验证。Fixer 生成安全补丁，Verifier 独立判定（不接受 Fixer 推理）。

组织标准检索

词法检索组织安全标准（CWE/密码/供应链/审计规范），仅作为审查参考，不参与风险决策。

能力边界（诚实声明）

  • 自动 merge 未启用 — 所有合并决策由人工执行
  • 完整 RAG 未完成 — 历史案例检索（C 链）处于 BLOCKED 状态
  • 生产自动修复未启用 — Fixer/Verifier 仅在隔离环境中运行
  • embedding 未启用 — 不下载、不生成向量
  • GitHub 写入默认关闭 — 只读审查
  • 自动 approve 未启用 — 审批由人工操作

快速开始

# 1. 导入镜像
docker load -i mp-console-image.tar

# 2. 配置
cp .env.example .env
# 编辑 .env 填入生成的密钥

# 3. 启动
docker compose up -d

# 4. 访问
open http://localhost:4730

安全模型

  • 🔐 服务端会话 — HMAC 签名 cookie + CSRF + TTL
  • 🛡 仓库 Allowlist — 服务端行级过滤，未授权仓库不可见
  • 🔒 网络隔离 — PG/MinIO 在内部网络，Console 绑定回环地址
  • 📝 审计追踪 — 每次操作记录五字段（snapshot/query/refs/state/run）
  • ⚠️ Fail-Closed — 缺失数据 = 拒绝，不降级

限制

MergePilot 目前处于内部试用阶段。以下功能受限或未启用： C 链历史案例检索（需模型缓存+密钥分发）、生产环境自动修复、 多用户 RBAC、公网部署。详见文档中的 LIMITATIONS。
