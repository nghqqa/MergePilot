# 路演 B · 瑞士风网页版（现场备用）

**主提交版是同级目录的 `MergePilot-决赛路演.pptx`（版本 A）**。本文件夹是自带电脑演示的备用版本，浏览器全屏播放。

## 使用

1. 双击 `index.html`（Chrome / Edge），← → 翻页，`Esc` 总览
2. 按 `P` 进演讲者模式：当前/下一页预览、逐页提词卡、计时排练、观众屏同步
3. 投屏卡顿按 `B` 切低功耗静态模式（内容保持完整可读）
4. 无法开浏览器时，直接放 `MergePilot-决赛路演-瑞士风网页版.pdf`（与网页 10 页一一对应）
5. `preview/B-01…10.png` 为逐页静态渲染图，可作最后兜底

## 依赖说明

- 联网时加载 Inter 字体、lucide 图标与入场动效，效果最佳
- 断网时自动降级为系统字体、无图标、无动画，内容始终完整
- 演讲备注已按页内置（`data-slide-id` 对应），演讲者模式逐页显示
