## Verification

- The M4-E gate is platform-aware. `conftest.py::_expected_for(os.name)`
  selects `(EXPECTED_PASS, EXPECTED_SKIP)` and `run_all.sh` loads them via
  `runpy` (no regex on a hard-coded integer). The gate asserts, for two rounds:
  `passed == EXPECTED_PASS`, `skipped == EXPECTED_SKIP`, `failed == 0`, `rc == 0`.
  An unexpected skip is NOT ignored.
- Current collection (169 tests):
  - Windows (`os.name == "nt"`): 166 passed / 3 skipped
    (3 = POSIX-only `TestPosixRealTreeStub`).
  - POSIX (`os.name == "posix"`): 158 passed / 11 skipped
    (11 = Windows-only cleanup/Job/guard classes).
- POSIX real tree-stub: 3/3 (success/error/timeout) via Docker python:3.10-slim.
- `verification.txt` records the run platform and per-round
  passed/skipped/failed/rc for both M4-E rounds.
- Real pgvector E2E via one-shot Docker `pgvector/pgvector:pg16` fixture
  (`docker-fixture-e2e.json`); `pgvector-e2e.json` binds to the current
  delivery digest.  Both are machine-generated, never hand-edited.
- The E2E covers two repository scopes, NULL-scope exclusion, stable ranking,
  no-match, stale/untrusted cases, schema/scope fail-closed paths, reader role
  attributes, denied writes, statement timeout, and unchanged legacy rows.
- M4-A/B/C/D regressions run twice from the M4-E gate (75/96/87/54).
