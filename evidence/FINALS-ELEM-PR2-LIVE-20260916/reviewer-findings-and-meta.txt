## 1. User-controlled parameter escapes the base directory

- File: `backend/src/interfaces/api/v1/demo_high_risk.py`
- Function: `demo_download` (`async def demo_download(name: str) -> FileResponse`)
- Key lines:
  - **L28** `DEMO_FILES_DIR = os.path.join(os.path.dirname(__file__), "demo_files_base")` — base dir.
  - **L41** `file_path = os.path.join(DEMO_FILES_DIR, name)` — **vulnerable**: raw, user-controlled `name` is joined with **no normalization and no containment check**.
  - **L42** `return FileResponse(file_path, filename=name)` — serves the resolved (escaped) path.
- `name` is an unsanitized `str` query parameter bound directly to the filesystem path. `os.path.join` does not neutralize `../`; a `../`-prefixed value re-parents the resolved path outside `DEMO_FILES_DIR`.

## 2. Arbitrary file read outside the base directory

- Any file readable by the process (relative traversal, or absolute path via enough `../`) is returned with HTTP 200 and its raw contents. No allow-list, no `realpath`+`commonpath` containment, no null-byte / separator filtering.
