# MergePilot Benchmark — Controlled Local Orchestration Comparison

> HEAD = `4b053ef` | NOT YET RUN | Review/Decision/Precision/Recall only

## What This Is

A **controlled local orchestration benchmark** comparing single-agent vs
multi-agent code review topology. Both groups use the same LLM API, same
fixtures, same timeout, same token budget. The ONLY variable is orchestration.

### What This Is NOT

- **NOT** real MergePilot controller/Gateway E2E
- **NOT** C3 replacement (C3 10/10 evidence is separate)
- **NOT** production HiClaw live
- **NOT** GitHub real PR workflow
- Does NOT use real Gateway, real controller, or real GitHub writes

## Groups

| Group | Adapter | Description |
|---|---|---|
| A | `SingleAgentAdapter` | One LLM call: review + decide. No multi-role handoff. |
| B | `MergePilotAdapter` | Reviewer → Fixer (independent contexts, 2+ LLM calls). Local orchestration implementing MergePilot-style topology. |

### Fairness

Both groups receive **identical** AdapterInput:
- Same model, same fixture SHA256, same timeout, same token budget
- No ground truth leaked to either adapter (see isolation section)
- No external tools (tool_allowlist is informational; no enforcement layer)

### Group B Scope

Group B implements:
- Independent Reviewer context (separate system prompt)
- Independent Fixer context (sees ONLY findings from reviewer)
- Deterministic handoff (structured JSON between roles)
- L2 risk assessment (reviewer assesses; no GT risk_label leaked)

Group B does NOT implement:
- Real patch application (metric downgrade)
- Deterministic verification (metric downgrade)
- Real Gateway/controller/GitHub (local LLM only)

## Metrics

### Supported (implemented in summarizer)

| Metric | Description |
|---|---|
| case_pass_rate | Semantic PASS / total (evaluator judges) |
| execution_completion_rate | completed / total |
| precision | TP / (TP + FP), finding-level one-to-one |
| recall | TP / (TP + FN) |
| F1 | 2PR / (P+R) |
| decision_accuracy | correct decision / total |
| mean/P50/P95 duration | seconds, from completed runs |
| total_tokens | sum across completed runs |
| audit_completeness | audit_complete=True / total |

### Unsupported (removed — no real patch/verify)

- ~~first_pass_fix_rate~~
- ~~final_fix_rate~~
- ~~verification_rate~~
- ~~rollback_success_rate~~
- ~~L2_miss_rate~~
- ~~RAG Recall@1/3/MRR~~
- ~~model_cost~~

These were removed because fix_applied/verification_passed/rollback_executed
are **model self-reported**, not deterministically verified. No fake metrics.

## Isolation

- `AdapterInput`: 7 fields (case_id, fixture_path, fixture_sha256, model,
  timeout, token_budget, tool_allowlist). **ZERO** ground truth fields.
- `CaseMeta`: full ground truth. **NEVER** passed to adapter.
- `SemanticEvaluator`: judges adapter output against CaseMeta **after** execution.
- `completed ≠ passed`: evaluator independently determines PASS/FAIL.

## Secret Safety

- Credentials: env var or `D:/goai/.llm-key` file only
- `error_detail`: sanitized codes only (`parse_failed`, `timeout`, `http_status_N`)
- No raw LLM response, no API key, no prompt content in output
- No Authorization header persisted

## How to Run

```bash
# Validate dataset
python benchmark/validate_dataset.py

# Run smoke
python benchmark/run_benchmark.py --smoke --case-id bm-01 --group A_single_agent --model deepseek-v4-flash

# Run full N=10
python benchmark/run_benchmark.py --group A_single_agent --model deepseek-v4-flash
python benchmark/run_benchmark.py --group B_mergepilot --model deepseek-v4-flash

# Summarize
python benchmark/summarize_results.py
```
