## 一、推荐路线与不做事项

**推荐路线 A**：复用 AgentTeams 底座（AgentTeams 控制器 + 角色化 Agent 运行时），以
mergepilot-isolated compose 为部署底架，先完成**单团队、单仓库**的后端驱动试点。

**路线 B**（拆轻量无状态 Agent 服务）仅作为未来备选，不与路线 A 并行实施。理由：角色契约
执行、Matrix 审计链、文件同步、停等恢复、工具护栏等已由五轮真实运行验证的能力都在底座内，
路线 B 需全部重造。

**不做事项**：演示平台（离线证据回放器）与生产服务不合并；K8s/多租户/微服务拆分不作为首版
前提；CRITICAL 级只报告不修复；Agent 不持有任何 GitHub 写凭据（见 §5 凭据边界）。

## 四、PR 生命周期与版本失效分支

```
开发者提 PR / 更新 PR（head_sha 变化）
    ↓ Webhook（幂等去重；force-push → 旧运行标注 STALE 并停止）
Reviewer Agent 审查（绑定 head_sha）
    ├─ 本轮未发现阻断项 → PR 标注审查报告（附检查范围与未执行项），通知维护者
    ├─ HIGH → 人工门停等（审批绑定 repo+PR+head_sha+run_id）
    │   ├─ 批准 → Fixer（仅改标记文件·测试冻结）→ 补丁工件交付（不自动 push）
    │   │   → Verifier 独立验证（干净环境重放 head_sha+补丁）
    │   │     ├─ PASS → 标注 "verified @ head_sha"，维护者手动合并
    │   │     └─ FAIL → 新尝试标识重试 ≤2 次 → 二次 FAIL 升级人工
    │   └─ 拒绝 → 本运行终态：fix rejected / verify locked / 运行 blocked · 证据归档
    └─ CRITICAL → 同 HIGH 流程，但只报告不修复
```

**版本失效与状态语义（硬规则）**：
- 审批与验证记录绑定五元组：repo + PR + head_sha + run_id + 补丁摘要。
- PR 更新（新 commit / force-push）→ 旧批准与旧验证结论**失效**；派发时与结果发布时复核 head_sha。
- "临时工作区补丁验证通过" ≠ "当前 PR head 已修复"——后者需 head_sha 未变且补丁已应用（或已由维护者合入）。
- 拒绝是**当前运行**的终态；同一 PR 后续可创建新运行（新 run_id），不受历史拒绝终态约束。
- 无阻断项的表述统一为 **"本轮未发现阻断项"**，并披露检查范围与未执行项；不使用 "safe merge"。

## 六、MVP 用户流程与最小前端范围

**首版入口**：GitHub（PR 评论/Checks 展示）+ IM（审批通知与动作）+ 薄操作台。不做大而全管理后台。

MVP 必备能力（**先是服务端契约与授权，前端保持简单**）：
1. 当前 PR/head 与运行状态（含 STALE/过期标注）
2. 审查报告、补丁工件、证据入口
3. 绑定版本的批准/拒绝（五元组校验）
4. 取消、失败原因、过期审批提示

**Demo 组件复用边界**：可复用 = 展示组件（步骤条/证据抽屉/KV/速查）与数据契约；仅回放、
必须重新接入生产服务的 = timeline/replay-provider 数据源、审批动作的真实写路径、授权与身份。

## 七、MVP 可靠性底线（前移到首次无人值守运行之前）

以下全部**先于**首次无人守候运行实现：
- 超时：LLM 调用 / 工具 / 整轮上限（额度未定，标"待配置"）
- 预算：执行中 token/调用计数与熔断（**网关日志是事后计量，不是硬护栏**——两者区分如实标注）
- 取消：进行中任务可取消且状态一致
- 失败恢复：worker 崩溃/重启后，任务状态与派发可恢复（sync token 重建已有实践）
- 审计：结构化事件链落 PostgreSQL

事件语义原则：
- 重复 Webhook → 幂等去重（delivery id）
- 乱序/过期事件 → 按 head_sha 与时间丢弃
- 重复审批 → 终态保护（REJECTED_TERMINAL 先例已验证）
- 派发幂等 → 事务号新规约（R1 教训：复用事务号会吞掉新委派）
- ctrl/worker 重启恢复 → reconcile + sync token 重建（已有实践）

重试 = 初次执行之外的次数，**采用新尝试标识**（如 `-fix-2`），禁止复用被作废事务号。
