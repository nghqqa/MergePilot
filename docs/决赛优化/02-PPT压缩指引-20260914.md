## 现场演示顺序（12 分钟）

1. `/rework`（3 min）：顶栏等级标签 → 场景 A 时间线 → 尝试 1 diff 与失败测试 → 退回原因 → 尝试 2 PASS → 场景 B/C/D 一屏。
2. `/pr4`（5 min）：候选 A 真实 SQL 验证链 ①→⑦ → 人工门：批准 → "回放：追加一次代码提交" → 再批准 **409** → 重置 → 三候选 SIMULATED 分区 → 运行元数据/服务状态（证据 SHA256 校验通过）。
3. RAG 页 + `/api/rag/status`（2 min）：策略 v2、证据路径、held-out 前后。
4. 边界收尾（2 min）：`/api/health.finals` 的 tiers；未完成项。
