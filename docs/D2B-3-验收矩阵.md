## 0. v1→v2 变更摘要

- **端点用 SOURCE_PROVEN 行号锚定**：每个 controller 调用的 Docker API 对应 `docker.go:<line>`（commit `849182a`）。
- **name-prefix 隔离 + labels mandatory（D2B-3B1.2 闭合）**：controller 创建的容器原生无 label，proxy 在 TRANSFORM 时**注入 4 项权威 labels**（scope/run_id/agent/hardened）。所有后续 nameprefix 操作（start/stop/json/archive/delete/**exec-create**）必须通过 `_inspect_authoritative`：Name 精确匹配 + 4 项 label 精确等于 config 值，缺一即 DENY。**labels 缺失不是兼容模式**；旧版无 label 容器必须清理或重新创建。
- **exec-create 现在属于 authoritative inspect 范围**（D2B-3B1.2）：inspect 失败 → 403，exec-create 不转发给 upstream。
- **新增 B5 label 伪造 8 类绕过**（B5.1-B5.8）：重复 key / 大小写 / Unicode / 空值 / JSON 类型 / 嵌套 / 前缀混淆 / null byte。
- **新增 D2B-3B1.2 authoritative binding 18 项测试**（`TestAuthoritativeBinding`）：valid+labels 放行、labels 缺失/Config 缺失/scope 错/run_id 错/hardened 缺失或错/agent 缺失或错/Name 错/labels 非 object/未知 agent name 全 DENY；exec-create 正确绑定注册 + inspect+exec 两次 upstream；manager role 有效绑定。
- **新增 B11（archive 投影）/ B13（image pull）**：v1.2.2 controller 的 SOURCE_PROVEN 端点。
- **名前缀**：`hiclaw-*`（v1.1.2）→ `agentteams-*`（v1.2.2，`changelog #1063/#1065` 硬切割）。

## 1. 测试基础设施（D2B-3B 必须先建）

| 设施 | 用途 | 形态 |
|---|---|---|
| `FakeUpstreamDaemon` | 模拟 dockerd：记录收到的 method/path/body，可编程响应（含 hijack upgrade 响应 `/exec/{id}/start`） | Python `socketserver`，纯内存，host 单测 |
| `ControllerStubClient` | 模拟 controller 发请求（按 §3 的 13 个 SOURCE_PROVEN 端点逐项） | Python `http.client` over unix socket |
| `ProxyHarness` | 起 proxy 进程（指向 FakeUpstreamDaemon 的 socket）+ 暴露 proxy socket 给 stub client | pytest fixture |
| `NamePrefixStub` | FakeUpstreamDaemon 对 `GET /containers/{name}/json` 返回的 inspect body，`Name` 字段可编程（匹配/不匹配 `agentteams-*`） | 同上 |

**约束**：不启动真实 dockerd、不启动 v1.2.2 AgentTeams、不访问真实 docker.sock。

## 4. 绕过用例（设计 §9 的每一项风险都要有对应测试）

| # | 场景 | 攻击 | 期望 | 关联风险 |
|---|---|---|---|---|
| B1 | 直连原 socket | stub 直接访问 `/var/run/docker.sock` | **部署层断言**：deploy 步骤在 controller 容器内**只挂** proxy socket；本测试断言 controller 容器 spec 无原 socket bind | B1 |
| B4 | 中转容器带 socket bind | `?name=agentteams-worker-evil`，body `Binds=["/var/run/docker.sock:..."]` 或 `Devices=[{Path:"/var/run/docker.sock"}]` 或 `Mounts=[{Type:"volume",Source:"docker.sock"}]` | 403（N6/N6b/N6c 三路径全覆盖） | B4 |
| **B5** | **label 伪造（8 子类）** | 见 §4.1 | strip 后注入权威值 | B5 |
| B6 | proxy RCE（代码层） | 静态审计 + fuzz：畸形 JSON、超长字段、Unicode 炸弹、chunked、慢速攻击 | proxy 不崩溃；超时 fail-closed | B6 |
| B7 | marker/pid 生命周期 | proxy 退出后 marker 仍存在；`validate_marker` 校验 pid 死 → marker 拒绝 | controller 阻塞 | B7 |
| B8 | 版本号协商 | `GET /v1.99/_ping`、`GET /v0.1/_ping`、`GET /_ping`（无版本） | allowlist 端点放行（版本通配） | B8 |
| B9 | 流式不缓冲 | `GET /containers/{name}/logs?follow=1`（若放开），上游持续推送 | proxy 流式透传，无 OOM | B9 |
| B10 | 镜像 digest 伪造 | `Image="allowlisted@sha256:abc... evil"`（注入空格/引号） | 解析失败 → 403 | B10 |
| B11 | archive 投影任意路径 | `PUT /containers/{name}/archive?path=/etc`（非 auth token 目录），name 匹配 | 403 或路径限定（proxy 校验 `path` 在 auth token 目录范围内） | B11 |
| B12 | exec 后访问 socket | `POST /containers/{name}/exec` 后 upgrade，exec 命令 `curl --unix-socket /var/run/docker.sock` | worker 无 socket（controller 不挂，§2.1）；exec 目标 name 校验 | B12 |
| B13 | pull 恶意镜像 | `POST /images/create?fromImage=evil@sha256:...`，非 allowlist | 403 | B13 |

### 4.1 B5 label 伪造 8 子类（设计 §7.3）

| # | 攻击 | 期望 |
|---|---|---|
| B5.1 | client 发 `Labels={"com.mergepilot.run_id":"victim"}` | strip 后 proxy 注入正确 run_id；转发 body `Labels["com.mergepilot.run_id"]` == proxy 值 |
| B5.2 | JSON 重复 key：`{"com.mergepilot.run_id":"a","com.mergepilot.run_id":"b"}` | Python `json.loads` 取最后值；strip 移除；注入权威值（测解析器行为） |
| B5.3 | 大小写：`COM.MERGEPILOT.RUN_ID`、`com.MergePilot.Run_ID`、`com.mergepilot.RUN_ID` | canonical（casefold）比较 → strip；不被绕过 |
| B5.4 | Unicode 同形/正规化：`𝐜𝐨𝐦.𝐦𝐞𝐫𝐠𝐞𝐩𝐢𝐥𝐨𝐭.run_id`（全角）、`com.mergepilo\u0074.run_id`（转义） | Docker label 是字节串；proxy NFKC 正规化 + 字节比较 → strip |
| B5.5 | 空值：`{"com.mergepilot.run_id":null}`、`{"com.mergepilot.run_id":""}` | key 存在即 strip（不论值） |
| B5.6 | JSON 类型：`Labels=[["com.mergepilot.run_id","x"]]`（数组） | body schema 校验 → DENY（body 解析失败） |
| B5.7 | 嵌套：`Labels={"com":{"mergepilot":{"run_id":"x"}}}` | Docker Labels 是 flat map；嵌套 → schema DENY |
| B5.8 | 前缀/null：`com.mergepilot.run_id.evil`、`com.mergepilot.run_id\x00evil` | 精确 key 匹配；前缀不命中；null byte → DENY |
