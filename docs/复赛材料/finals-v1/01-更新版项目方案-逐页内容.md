# MergePilot 复赛更新版项目方案

冻结基线：`v0.1.0-preview.4`，tag 指向 `5bb2635`；正式 Release 为 Pre-release。M9-K 同机黑盒验收通过，独立物理机验收仍为 `EXTERNAL_BLOCKED`。

## 15 页叙事与逐页证据

1. **定位**：把多 Agent 协作放进可回滚、可审计的交付控制面。证据：README、正式 Release。边界：Preview，不是生产系统。
2. **初赛承诺与复赛兑现**：角色拆分收敛为 4 个运行时 Agent、6 类职责、确定性交接。证据：`config/souls/`、`tools/agentteams/`。
3. **用户问题**：PR 协作中的权限、状态、幂等和失败恢复不可见。证据：M9 real PR 与回滚记录。边界：案例为受控 Preview 证据。
4. **总体架构**：Agent、Skill、Controller、Gateway、数据/证据服务分层。证据：`tools/workflow-controller/`、`tools/policy-gateway/`。
5. **4 Agent / 6 职责**：Manager/Coordinator、Reviewer、Fixer、Verifier；Triage 下沉为 diff-parse/risk-classify，Fix Planning 收敛为规划阶段与状态机。边界：不写“6 个已部署 Agent”。
6. **6 Skill DAG**：`diff-parse`、`risk-classify`、`sast-scan`、`test-runner`、`pr-lifecycle`、`case-retrieval`。证据：`skills/`、M9 门禁。RAG 当前为 advisory。
7. **Controller**：状态机、CAS、超时 HOLD、幂等和回滚由 Controller 统一推进。证据：`tools/workflow-controller/`、M9 revision matrix。
8. **Gateway 与 MCP**：Policy Gateway 决定 ALLOW/DENY/HOLD；GitHub MCP 为隔离服务，PAT 只进入该服务。证据：`tools/policy-gateway/`、`config/m5-0c/`。
9. **数据与证据**：PostgreSQL 保存任务/阶段/Outbox/审计；pgvector 提供案例检索；MinIO 保存对象与配置证据；本地 Trace 与结构化审计形成关联链。云 SLS 仍规划中。
10. **Fail-closed 与回滚**：revision、审批、资源 owner 或状态漂移即拒绝；失败后逆序清理并复核。证据：M9-K cleanup/rollback evidence。
11. **真实 E2E**：最终候选在同机完成 Check→Install→Doctor→Start→Smoke→Stop→再 Start→负向→Cleanup。证据：仓内验收索引与正式 Release。边界：同机，不是外部验收。
12. **只读控制台**：页面/API 双 200，405/404/403 边界通过；GET-only、loopback-only、五项 NOT_VERIFIED 常驻显示。证据：M9-K screenshot 与 lifecycle evidence。
13. **工程交付**：正式 Release 提供 7 项资产、9 个离线镜像、`images-oci.tar` 约 847MB；支持 Check/Install/Doctor/Start/Status/Stop/Cleanup。证据：Release manifest 与 SHA 清单。
14. **评测与限制**：门禁 `2471 passed / 0 failed / 20 skipped`；same-machine accepted；external blocked；不声称生产集成、数据库或生产验证。
15. **下一步**：独立 Windows 11 机器验收、更大真实样本、云端可观测出口；开放计划按真实完成状态推进。
