# MergePilot v0.1.0-preview.4 代码包说明

正式 Release：<https://github.com/nghqqa/MergePilot/releases/tag/v0.1.0-preview.4>。Tag 指向 `5bb2635`，Pre-release、非 Latest。

## 支持范围

Windows 11 + WSL2 Preview；传输配置 `wsl-user-relay`；Windows 发布边 loopback-only（127.0.0.1:8600/8090）。

## 下载与校验

下载 Release 的 7 项资产，先执行 `checksums.sha256` 和 `SHA256SUMS` 校验，再运行 `Check`。校验失败或镜像集合不一致时，Install 在 `docker load` 前 fail-closed。包含 9 个离线镜像，OCI tar 约 847MB。

## 生命周期

入口为包内 `bootstrapper.ps1`：`Check`、`Install`、`Doctor`、`Start`、`Status`、`Stop`、`Cleanup`。Standalone 模式不需要源码仓或 Git；`--build-from-source` 才检查源码构建布局。Cleanup 按 install manifest 的属主边界处理资源，无属主记录时保守保留。

## 样例输入输出

样例投影和状态输出位于仓库 `docs/preview/projections/`；完整运行证据与输入输出索引位于 `evidence/`。Demo 使用 `complete`、`failed`、`stale` 三种明确标注的投影。

## 已验证结果

M9-K 同机黑盒完成完整生命周期：页面/API 200，POST 405，未知路径 404，恶意 Host 403；Stop/再 Start 和双次 Cleanup 通过。门禁基线 `2471 passed / 0 failed / 20 skipped`。

## 限制

这是 Preview，不是 production ready。独立物理机验收仍为 `EXTERNAL_BLOCKED`；`direct_routing_verified=false`；云端 SLS 和生产集成未验证。首次 Start 的 preflight 是 exit=0 的 run-to-completion 任务。发布包不含秘密。
