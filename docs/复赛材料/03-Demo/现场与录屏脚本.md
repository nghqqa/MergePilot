## 3:40-4:30 stale与恢复

在预录环境中停止上游或播放预录片段：最后良好数据保留，状态转为陈旧；上游恢复后自动回到Complete。

口播：上游失联时不清空证据，也不继续显示刚刚更新，而是保留最后真相并标注年龄。

现场如果环境不稳定，不执行容器操作，直接播放预录片段。

## 4:30-5:30 权限与回滚

切回PPT架构页或控制台证据栏：

- Worker零PAT；
- Gateway决定ALLOW / DENY / HOLD；
- revision、审批和状态不匹配即fail-closed；
- rollback后重新验证并检查residue。

口播：Agent提出动作，Controller和Gateway决定它是否能发生；回滚不是第二次盲写，而是根据revision和journal事实执行。
