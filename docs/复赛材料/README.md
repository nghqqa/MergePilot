# MergePilot 复赛材料

本目录是复赛提交物的单一材料入口。当前阶段只冻结要求、口径和证据规则；项目功能与 Preview 可用性验收稳定后，再生成最终 PPT、PDF、代码包说明和 Demo 视频。

## 使用顺序

1. 先读 [00-材料约束.md](00-材料约束.md)。
2. 所有页面、口播、视频字幕和提交说明必须遵守其中的真实性与术语约束。
3. 最终材料只能引用已冻结的提交、Release、测试结果和 evidence，不从开发中状态推断能力。

## 计划交付物

| 目录或文件 | 用途 | 当前状态 |
|---|---|---|
| `00-材料约束.md` | 官方要求、统一口径、真实性边界 | 已建立 |
| `01-更新版项目方案/` | PPT、PDF及逐页证据指针 | 待项目冻结后整理 |
| `02-代码包说明/` | 运行入口、依赖、配置、样例和验证证据 | 待 Preview 验收稳定 |
| `03-Demo/` | 现场演示脚本、录屏脚本和故障预案 | 待最终版本确定 |
| `04-声明证据矩阵/` | 每项声明对应 commit、测试和 evidence | 待最终统一复核 |
| `05-评委问答/` | 架构演进、边界、风险和开放计划 | 待材料成稿后整理 |

历史初赛材料不迁入本目录覆盖修改；需要对照时只引用其历史快照。
