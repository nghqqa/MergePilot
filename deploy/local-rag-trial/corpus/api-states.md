# 检索服务状态契约

检索接口必须如实返回六种服务状态之一，任何实现不得把失败伪装成空结果。

## 六状态定义

hit 表示命中且结果非空。empty 表示索引正常但无匹配结果。
model missing 表示请求的嵌入模型未注册。index stale 表示索引行与
激活模型的摘要或版本不一致。provider unavailable 表示嵌入服务不可达。
error 表示未预期的内部错误，例如数据库不可用。

## 降级原则

服务不可达时返回显式降级状态与原因，响应头携带服务状态标记。
空结果与降级是两个不同的状态，前端必须区分展示。

## 观测

每次查询记录延迟、状态、命中数与被丢弃的无引用行数。指标从真实
查询日志推导，延迟分位数在数据库内计算。错误状态在数据库不可写时
由进程内存计数补齐。
