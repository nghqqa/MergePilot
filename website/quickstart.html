快速开始

前提：Docker 与 Docker Compose v2；一个 GitHub 账号；约 10 分钟。

1. 获取源码与模板

git clone https://github.com/nghqqa/MergePilot.git
cd MergePilot && git checkout v0.2.0-beta.6-rc.15
cd deploy/selfhost

2. 填写配置

cp .env.example .env && chmod 600 .env

必填项（生成命令见 配置参考）： POSTGRES_PASSWORD、CONSOLE_SESSION_SECRET、 GitHub App 四项、OAuth App 两项、LLM 四项。 App 的创建步骤见 多租户与 webhook。

3. 一键检查后启动

node preflight.mjs                    # 只读检查，关键项失败即退出
docker compose --env-file .env up -d
node preflight.mjs --live             # 启动后活体探测
curl http://127.0.0.1:48500/api/health

首次启动自动完成数据库 schema 初始化（至 v23），无需手工建表。

4. 创建管理员

打开 http://127.0.0.1:48500/multiuser，用 GitHub 登录。 首个用户需要先经邀请：由既有管理员按你的 GitHub 数字 user id 创建邀请后重新登录即自动认领（见 多租户与 webhook）。 空库的首个管理员可经一次性初始化命令创建（见 配置参考 的 MU_ALLOW_FIXTURE_LOGIN 说明——完成后必须关闭）。

生产对外暴露：必须前置 TLS 反向代理并把回调地址改为 https 域名。 明文 HTTP 不允许承载已认证会话（会话 Cookie 自带 Secure 属性）。详见 安全加固。
