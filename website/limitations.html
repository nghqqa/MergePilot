验证范围

截至 2026-10-25，rc.35.6-rc8 已作为官方预发布发布，维护者生产实例已受控换版至 rc.35.6-rc8.2；角色登录验收覆盖 platform_admin（GitHub）/maintainer（Gitee）/contributor（GitHub，含越权拒绝实证），auditor 等其余角色未做真实登录验收 （换版 2026-10-18T12:37Z；T+1h 观察满窗通过——33 次采样全部 healthy、零重启、 窗口内错误日志 0 行）；首位未参与开发的真实用户试用仍待验。 演示夹具登录不等于 OAuth 接入验收，预置发现与补丁证据不等于真实模型产出或测试执行结果。

知识库引用（RAG V1）能力边界：run 页按需检索知识库并展示可追溯参考引用——已实现。 worker 执行期自动检索与引用快照持久化——未建设（接口与契约已备）。 生产语义检索已通过隔离+机器通道端到端验证；生产 run 页面级展示待维护者 OAuth 登录后验收（本机 fixture 登录不适用于生产环境）。

真实手机、200% 真缩放与读屏器尚未验证；候选环境中远端读取失败时，完整合并资格展示仍受限。 失败提示与禁用行为已检查，不能据此认定该环境具备真实提交或合并资格。 使用者可先按首次使用的只读路径核对理解与导航。

安全边界

  • 写入全部受控：机器人提交修复与合并 PR 都需维护者逐次「预览 → 确认」；不存在自动批准、自动合并或 required check 设置。
  • CI 状态为只读读取，作为合并资格输入；CI 未配置、未通过、读取不完整时合并一律不放行。
  • LLM 供应商由使用者自选自配，key 只存使用者自己的环境。
  • 所有审查结论与证据落在使用者自己的数据库与证据卷中。
  • platform_admin 不可经邀请授予——API 403、claim 拒绝、DB 约束三层拦截；平台管理员同样无审批/应用/合并权（平台管理与审查裁定分离）。
Beta 通道说明：0.2.0-beta.6-rc.N 为快速迭代通道，接口与配置项可能随版本调整； 生产使用建议钉住 digest 并在升级窗口验证（见升级与回滚）。
